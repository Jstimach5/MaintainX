# User Guide (Technicians & Requesters)

Works in any phone or desktop browser. On your phone, open the app URL and
use your browser's **Add to Home Screen** for one-tap access.

## Technicians

**Your work.** Dashboard → "Assigned to me", or Work orders → tick
**Mine**. **Schedule** shows the same work on a calendar (and timeline) —
yours only. You can act on jobs assigned to you, to your team, or
unassigned jobs — not on someone else's.

**Doing a job:**

1. Open the work order → tap **Start work**.
2. Work through the **procedure steps** if one is attached. Required steps
   block completion. If an inspection step fails, say what you found — a
   comment is usually required, and the system flags the job (and can file
   a corrective request automatically).
3. **Pictures**: tap "Add pictures / files" — on a phone this opens the
   camera. Before/during/after shots help the next person.
4. **Log time** in the side panel (hours + minutes).
5. **Parts & materials used**: type the part name, quantity, and cost each
   — the job totals the cost. Leave cost blank if you don't know it; tap ✕
   to remove a mistaken line.
6. **Meter readings**: the job page lists every meter on the machine —
   enter the current hours/miles/fuel while you're standing at it.
7. Tap **Mark completed…**, write what you did, record actual downtime if
   the machine was down, and complete.

**Meters.** Also available standalone: Meters → open the meter → enter the
reading. If a reading looks impossible (an hour meter going backwards) the
app will say so; tick the rollover box only if the meter really rolled
over.

**Asset status.** If a machine goes down, open its asset page and set the
status (with a note) so managers see it immediately.

**Found another problem?** Submit a request (Requests → New request) —
managers review and turn it into a work order.

## Requesters

1. **Requests → New request** (or your site's public portal link).
2. Say what's wrong, where it is, how urgent, and add pictures.
3. Track it on the Requests page: Submitted → Under review →
   Approved/Declined → Converted to work order. You'll get an in-app
   notification (bell icon) when it's decided and when the work is done.
